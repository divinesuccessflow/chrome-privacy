WriteAI — Privacy Policy

Last updated: February 15, 2026

What data we collect

WriteAI does not collect, store, or transmit any personal data to our servers. Your API key and usage statistics are stored locally in your browser using Chrome's storage API.

How text processing works

When you use grammar check or rewrite features, the selected text is sent directly from your browser to OpenAI's API using your own API key. We never see, intercept, or store this text.

Data stored locally

  • Your OpenAI API key (encrypted in Chrome's storage)
  • Daily usage count (resets each day)
  • Total usage statistics

Third-party services

This extension communicates only with api.openai.com for AI text processing. OpenAI's privacy policy applies to data sent to their API: openai.com/privacy

Permissions explained

  • activeTab: To read selected text on the current page when you click the extension
  • storage: To save your settings and usage stats locally
